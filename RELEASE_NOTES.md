# Proxy Press v0.10.1

- Empty decks now emphasize adding cards. Preview offers a direct route back to import when the card list is hidden, and the deck menu holds the token action.
- Saved order imports can be resumed from an empty deck. Closing the import drawer returns keyboard focus to Add cards.
- Card filters show when the artwork filter is active and offer a quick reset when no cards match. Quantity and options controls identify their card for screen readers.
- Deck and card confirmations use in-app dialogs, and removing a card offers Undo.
